# 判定范式归纳 v2（55 项指标 → 8 类范式：A1 / A2 / B / C / D / R5 / R6 / E）

> **目的**：55 项指标不是 55 个独立问题。先归纳"判定范式"，每种范式跑通一次，同类指标只是参数填空——**类结构只随范式变，不随指标变**。
> **依据**：`指标映射表.md` §三（55 项公式）、`类与层级.md` §2.9.3（指标 14 判定范式）、大王 2026-11-08 两轮批注（A 拆分为 A1/A2、城区须建公式）；2026-11-09 补 R5/R6 两类（城区手册实证）。
> **结论**：**8 类范式（城区手册实测后析出 R5 极值型、R6 加权型），55 项全覆盖，无遗漏无重叠。**

> 2026-11-09 增补 **R5 极值/周期**、**R6 加权/复合**两类：城区手册 39（最长轮候）、37（高峰车速加权）原先被笼统归入 D「密度/均值」，本轮析出为独立范式，D 收敛为纯「÷面积或人口」型。

**三条分界（最容易混）**：

1. **A1 与 A2**：看「这个结论有没有一个现成字段能直接回答」。有 → A1；要多项核查才能答 → A2。
2. **A2 与 B**：B 判的是**设施的有无与规模**（未配建 / 配建不达标 / 达标）；A2 判的是**对象的多准则达标**（核查项命中）。
3. **只有 B 需要 `IndicatorJudgement`（指标判断）层**；A1/A2 的判断颗粒落在**被检实体**上（楼栋、街区），不在指标上。

### B 存在性/阈值（6 项）

```
对象级：未配建 / 配建不达标 / 达标   →   结果 = count(判断 ≠ 达标)
```

- **B1 三值**（9、10、14、20、21）：有"未配建"态，必须分三值。
- **B2 二值**（11 停车缺口）：只判"泊位/户 < 1"，无"未配建"态 → 退回 `count(小区, 泊位/户 < 1)`，**不建判断层**。
- **已实现**：14（未配建 1 / 配建不达标 22 / 达标 30 → 城区 23）。
- **通病**：缺场地明细（名称/年代/配套），是**必须 mock** 的范式。

### C 比率（17 项）

```
结果 = 分子聚合 ÷ 分母聚合 × 100%
```

- **C1 空间覆盖**（19、22、27、48）：需**坐标 + 用地边界**。以 27 绿道为例，官方测算方法为「建成区内绿道两侧 1 km 服务范围覆盖的**建成区居住用地面积** ÷ **建成区总居住用地面积** × 100%」——两个不同的"面积"，**不可混用**。
- **C2 一般比率**（31、32、33、38、40、41、42、44、47、50、51、52、54）：纯计数比/量值比。
- **风险**：分子分母若跨层级，须先定"聚合到哪一级再相除"。

### D 密度/均值（4 项）

```
结果 = 总量 ÷ 面积（或人口）
```

- 29、30、43、53。分母多为 `BuiltUpArea` / `BuiltUpResidentialLandArea` / `PermanentPopulation`，**复用密集**。
- ⚠️ **2026-11-09 修正**：原 37（高峰车速加权）、39（最长轮候极值）已从 D 析出，分别归入新增的 **R6**、**R5** 范式（见下）。

### R5 极值/周期（1 项）

结果 = MAX(时长) | 库存面积 × 12 ÷ 近 N 年年均

- **归属**：39（公租房保障最长轮候时间）。T13（商品房库存去化周期）同构，属自治区特色指标 T 系列，**不在研究范围**。
- **结构**：取样本极值（最长轮候月数）或周期（库存去化月数），非比率、非均值。
- **本体要件**：时序观测 `轮候时长` 取 `MAX`；结果归 `AssessmentResult.value`（数值），不进比率范式。
- **来源**：《自治区城市体检工作手册（2026 年版）》城区指标 39；参考标准建保〔2019〕55 号（≤36 月）。

### R6 加权/复合（1 项）

结果 = Σ(分段观测值 × 权重) ÷ Σ权重

- **归属**：37（城市高峰期机动车平均速度）。
- **结构**：先算各路段平均行程速度，再按车道公里（统计时段当量小汽车 × 道路长度）加权——分段求速后加权，非简单均值。
- **本体要件**：需 `路段车速观测` 集合 + `车道公里权重`；结果归 `AssessmentResult.value`。
- **来源**：手册城区指标 37；参考标准 GB/T 51328-2018（快速路≥30、主干路≥20 km/h）。

### E 求和/缺口（4 项）

```
结果 = Σ 量值 | Σ(需求 − 供给) | 本年 − 上年
```

- 12、15、28、36。12 与 15 有真实字段，最省事。

## 五、城区 29 项：**必须建公式，结果值只作校验**

大王 2026-11-08 批注：样本市城区表给了结果值，但**不代表真实情况**；每个指标都有官方测算方法，**分子分母必须建**；多个指标共用同一分母（如"建成区面积"）时更应统一到城区对象上。

**三层结构**：

| 层 | 内容 | 现状 |
| --- | --- | --- |
| ① **口径层（必须建）** | 公式 + 分子/分母引用的原子量 | 已建《指标公式展开表》城区 29 项 |
| ② **输入层** | 实测的分子、分母（或只有结果） | 城区表**只有结果**；多数分子分母缺 |
| ③ **校验层** | 用①算、与②结果对账，差异超阈值即报 | ⏭ 待建（阈值建议 5%） |

**"统一分母"的正确做法——建「量字典」**：每个量只定义一次（名称/定义/口径/单位/来源），指标只引用。

| 量（URI 名） | 中文 | 被哪些指标复用 |
| --- | --- | --- |
| `BuiltUpArea` | 建成区面积 | 30、43、53 |
| `BuiltUpResidentialLandArea` | 建成区总居住用地面积 | 27（分母）、19、22 |
| `BuiltUpConstructionLandArea` | 建成区建设用地面积 | 48 |
| `CityRoadLength` | 城市道路长度 | 30 |
| `PermanentPopulation` | 常住人口 | 29 |
| `GreenwayCoveredResidentialLandArea` | 绿道 1 km 覆盖的居住用地面积 | 27（分子） |

> ⚠️ **`BuiltUpArea` ≠ `BuiltUpResidentialLandArea`**：字面像，语义不同。绿道/中学/公园的分母是**建成区总居住用地面积**，不是建成区面积。统一的是"同名同义的量"，不是"看起来像的量"。

**对账的价值**：算出 5.12、表里 5.30 → 差 3.4% → 要么口径不同、要么填报有误。这等于给数据做**口径体检**（城区表"应急供水 5.90%""智慧化水平（千米）"这类异常会被直接揪出）。
