# 55项基础指标 · 数据对象拆解

> **用途**：为每个体检指标拆解其底层 `DataObject`（数据对象），用于丰富 `03-本体模型/` 的 `DataObject` 层，供大王审核后并入 `类与层级.md` §2.8 与 `属性与关系.md`。  
> **来源口径**：55 项默认与 **建办科〔2026〕16号 附件1《城市体检基础指标体系》** 一一对应（大王 2026-09-23 拍板）。  
> **维度主轴**：按项目五级主轴（住房 / 小区 / 社区 / 街区 / 城区）归类；手册「问题整治」两项（54、55）并入城区维度。



---

## 一、拆解原则（数据对象三分类）

依据大王的拆解口径，`DataObject` 分三类（与 `类与层级.md` §2.8 一致），统计逻辑由对象的属性决定：

| 类型         | 定义                                                                                                                                                           | 典型例                                                                                                                                                                                                       |
|--------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **实体对象** | 可独立存在的领域实体（设施 / 用地 / 场所 / 事件），新建 `DataObject`                                                                                           | 养老服务设施、充电桩、中学、桥梁、历史建筑、道路、负面事件                                                                                                                                                   |
| **基础量**   | 用于比值 / 密度计算的数值型底数（分母 / 分子）。分两类：① 独立采集的底数；② 由实体类属性聚合的**派生量**（如居住用地面积 = Σ `Land.ResidentialLand.landArea`） | 建成区面积、常住人口数、城市道路长度                                                                                                                                                                         |
| **复用实体** | 复用 `SpatialUnit` 子类 / 主干类 / `RenewalObject` 子类，状态属性直接挂上，**不新建 DataObject**                                                               | 住宅(=Building，用途住宅)、小区(=ResidentialQuarter)、体检问题(=Problem)、城市更新项目(=RenewalProject)、老旧街区/厂区(=OldBlock/OldIndustrialArea)、城中村(=UrbanVillage)、高层民用建筑(=Building 属性筛选) |

> **大王两条示例的落地**：
>
> - 「需要进行数字化改造的住宅数量」→ **复用实体型**：数据对象是「住宅」，复用 `SpatialUnit.Building`（用途=住宅），由住宅的「数字化改造需求」属性决定结果；
> - 「未达标配建养老服务设施的社区数量」→ **实体对象型**：数据对象是「养老服务设施」，由其「所属社区 / 名称 / 规模 / 配建达标」等属性决定结果。
