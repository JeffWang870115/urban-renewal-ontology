# 城市体检与更新本体研究

> 构建「城市体检 → 问题识别 → 城市更新」贯通的领域本体，统一概念口径，使**体检指标、问题短板、更新项目**三者之间可追溯、可推理。

## 关于本仓库

- **收录范围**：本项目**自建**的研究成果——概念清单、本体模型（类 / 属性 / 约束 / 查询）、55 项指标映射、调研成果与研究报告，以及配套生成脚本。仓库以 **Markdown / YAML 为源、`.ttl` / `.shacl` / `.sparql` 为机读产物**。
- **不收录**：第三方与官方原件（他人交付的本体文件、地方交付的成果件、官方工作手册 PDF 等），涉及他人著作权且体积大；另含本机手工备份与本地工具数据。以上由 `.gitignore` 排除。
- **实证数据已脱敏**：报告中涉及地方实例的实测数值（人口、户数、面积、指标实测值等）已做泛化处理，仅保留字段结构与量级；被引用的城市以「样本市」代称。方法论、算法参数（如评分区间、参考值）与结构发现**完整保留**。

## 一、目标

见上。核心是给「体检查出的问题」到「更新项目」之间补上一层**可计算的语义**。

## 二、为什么需要本体

- **两套话语不互通**：城市体检按「维度—指标」组织，城市更新按「对象—项目—资金」组织，中间缺一层可计算的语义，导致「体检查出的问题」无法自动关联到「更新项目」。
- **同名不同义 / 同义不同名**：小区、社区、居住区、街区在不同标准里层级和口径不一致，跨部门数据无法直接对齐。
- **需要被固定的东西**：有哪些类、类之间什么关系、指标落在哪个类上、问题如何触发更新。

## 三、范围（本期）

**纳入**：城市体检评估；城市更新（老旧小区改造、城中村改造、老旧街区与老旧厂区提升、基础设施更新）。

**不纳入**：房屋安全体检（单体建筑结构鉴定）、土地一级开发、房地产市场监管。

## 五、方法（四步）

1. **收口术语**：从政策与标准中提取概念，进 `02-术语与概念/概念清单.md`，先统一口径再谈建模。
2. **定类与层级**：确定顶层类，再逐级细分，进 `03-本体模型/类与层级.md`。
3. **定关系与属性**：重点是「评估结果 → 问题短板 → 整治建议 → 更新项目」这条闭环链。
4. **挂指标**：把体检指标映射到具体类与属性上，进 `04-指标映射/`。这是检验本体好不好用的硬指标——挂不上去就说明类设计有问题。

> **决策 7 细节**：视觉风格 = **现代中性 · 混合版**（界面浅色、**中间图谱画布保留深色**）；配色 = **语义域配色体系**，六域各占一色——主干闭环（蓝，**唯一实心**作焦点）／指标内核（紫）／指标双轴（青绿）／空间主轴（珊瑚）／更新要素（草绿）／政策依据（琥珀）；**深色档域色仅限 `.canvas` 作用域，不得外溢**。规范文档：`05-产出/原型方案/视觉规范-现代中性-语义域配色-v1-20261011.md`。
>
> **决策 8 细节**：`_gen_ttl.py` 的 `SUB` 字典原有一处重复键 `"DataObject": None,`（Python 重复键取末值），把 `DataObject` 的 7 个分类父类声明行整个覆盖，产出「被 `rdfs:subClassOf` 引用、却从未声明为 `owl:Class`」的类。**处置**：① 删除该重复键，7 类归位为 `DataObject` 子类；② 原防漂移断言是单向的（只查「已声明 URI 是否见于源 md」），**新增反向断言**——凡被当作父类或被属性定义域/值域引用的类必须已声明，否则构建失败。`_to_graph_json.py` 的同类检查同步归零。
>
> **决策 9 细节**：实测对比见 `05-产出/原型方案/G6-A与B对比-20261012.md`。**体积**：134 KB → 1.48 MB（+1.38 MB 库文件，**该库不入公开仓库，由 `.gitignore` 第 5 条排除**）。**渲染**：SVG → Canvas（视觉规范的 CSS 变量块不可复用，须转写 JS theme）。**布局**：现引擎三次运行**逐字节一致**；G6 力导向**三次运行 md5 全不同（非确定性）**。**G6 无内置标签避让**，须自写。取舍理由：现引擎已达标且更轻更稳；G6 的价值在**阶段二 30+ 现成插件**（Minimap / Tooltip / Timebar / LassoSelect / Contextmenu / Hull / History 等，UMD 导出 113 项）。另记两个 G6 坑：① 配置里的样式函数**每次绘制重新求值、会覆盖 `updateNodeData` 写入的值**（`labelText` 须用静态值）；② 视口 API 为 `getTransforms()` / `getViewportByCanvas()`，**无 `getTranslate()`**。
