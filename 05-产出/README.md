## 二、规则

1. **产出必须可追溯到过程文件**：报告中的每个论断，能指回 `02-术语与概念/概念清单.md` 或 `03-本体模型/` 的具体条目。
2. **产出带版本**：文件名后加日期，如 `城市体检与更新本体说明-v1-20260909.md`，不覆盖旧版。
3. **图表源文件与导出文件都保留**，图改了要能重新导出。
