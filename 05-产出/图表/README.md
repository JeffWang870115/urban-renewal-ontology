## 二、口径要点（画图时钉死的）

- 术语：城市体检（Urban Physical Examination）≠ 房屋安全体检；城市更新（Urban Renewal）为上位概念，老旧小区改造是其子类；社区/小区/街区注明层级，不互换。
- 命名：类大驼峰（`AssessmentResult`），属性小驼峰（`locatedIn`）；首次出现附中文+英文。
- **两组 `AssessmentResult` 子类正交非互斥**（按等级 vs 按算法）；**`RemediationSuggestion` 两子类二者择一互斥**（SHACL `maxCount 1`）。
- 分尺度：四档共用一套标尺、全市读绝对档位、下级读同级分位；全市评级不可反推下级（聚合悖论）；楼栋级暂缓（布尔 vs 四档不同构）。
