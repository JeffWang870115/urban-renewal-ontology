## 〇、一句话说明

按甲-精简版重构评价规则：**删 3 个空壳类、加 4 个类（2 词表 + 2 实体）、加若干属性、`grade` 改四档**。

## 一、变更清单（逐项）

### 1.1 删除 3 个类（空壳零实例）

| 类                 | 中文     | 现状              | 删除理由                              |
| ----------------- | ------ | --------------- | --------------------------------- |
| `AssessmentRule`  | 达标评价规则 | 仅 label+父类，0 实例 | 职责并入 `EvaluationRule`；与同事原件同名造成混淆 |
| `WarningRule`     | 预警规则   | 仅 label+父类，0 实例 | 输出维度改词表 `EvaluationOutput_二元预警`   |
| `CrossDomainRule` | 跨域规则   | 仅 label+父类，0 实例 | 算法维度改词表 `EvaluationMethod_跨域组合`   |

**删除影响**：SHACL 的 `sh:in` 类清单（第24行）需同步移除这 3 个 URI——但实测该清单**不含**这三个类，故**无需改 SHACL 此处**。

### 1.2 新增 2 个受控词表类

| 类                  | 中文   | 成员（实例）                  |
| ------------------ | ---- | ----------------------- |
| `EvaluationMethod` | 评价方法 | 直接比较 / 占比化 / 均值化 / 跨域组合 |
| `EvaluationOutput` | 评价输出 | 四级等级 / 二元预警             |

生成方式：加入 `_gen_ttl.py` 的 `VOCAB` 字典（第 108 行附近），由第 411–414 行统一生成 `a ur:XXX` 实例，**类结构不变、未来加成员只加字典一行**。

### 1.3 新增 2 个实体类

| 类                     | 中文    | 关键属性                                                                                                     |
| --------------------- | ----- | -------------------------------------------------------------------------------------------------------- |
| `EvaluationReference` | 评价参考值 | `forIndicator` / `appliesTo` / `validPeriod` / `referenceValue` / `ratingBand` / `basedOn` / `direction` |
| `DerivedRatio`        | 派生比值  | `derivedFrom` / `ratioValue` / `ratioOf`                                                                 |

### 1.4 新增/修改属性

| 属性                          | 类型   | 定义域→值域                                   | 说明                                |
| --------------------------- | ---- | ---------------------------------------- | --------------------------------- |
| `evaluationMethod`          | 对象属性 | `EvaluationRule` → `EvaluationMethod`    | 规则用什么算法                           |
| `evaluationOutput`          | 对象属性 | `EvaluationRule` → `EvaluationOutput`    | 规则输出什么                            |
| `usesReference`             | 对象属性 | `EvaluationRule` → `EvaluationReference` | 规则挂哪条参考值                          |
| `evaluates`                 | 对象属性 | `EvaluationRule` → `Indicator`           | 规则评价哪个指标                          |
| `forIndicator`              | 对象属性 | `EvaluationReference` → `Indicator`      | 参考值针对哪个指标                         |
| `basedOn`（复用既有）             | 对象属性 | → `PolicyStandard`                       | 参考值依据来源                           |
| `referenceValue`            | 数据属性 | `EvaluationReference` → decimal          | 锚点值（**解禁 C5**）                    |
| `ratingBand`                | 数据属性 | `EvaluationReference` → string           | 结构化四档边界（**解禁 C5**，见 §三决策点）        |
| `direction`                 | 数据属性 | `EvaluationReference` → string           | 正向/逆向                             |
| `ratioValue`                | 数据属性 | `DerivedRatio` → decimal                 | 派生占比值                             |
| `ratioOf`                   | 数据属性 | `DerivedRatio` → string                  | 占比口径说明                            |
| `validPeriod` / `appliesTo` | 数据属性 | `EvaluationReference` → string           | 时期/适用范围                           |
| `grade`（修改）                 | 数据属性 | `AssessmentResult` → string              | 枚举由三档改**四档**（仅文档口径，SHACL 无枚举约束可改） |

> `evaluatedBy`（Indicator → EvaluationRule）**保持不变**，是规则的反向入口。
