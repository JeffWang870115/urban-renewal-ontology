# 数据接入标准作业程序（SOP）v1

> **适用范围**：将外部权威统计（四张 xlsx：街区 / 社区 / 小区 / 楼栋）与衍生文档（docx 专题报告、pdf 自评表、手册）接入本体实例层（`06-实例数据/`）的统一流程。
> **目的**：固化五条主线——**xlsx 基线权威、按名匹配、剔除同步、脱敏红线、断言校验**，把已踩过的坑变成不允许再踩的规则。
> **版本**：v1（2026-11-14 提炼自 四表范围对照表 / 社区维度试点 / 指标11-mock v2 / 街道尺度停车推算 / route1–3 试点）。

---

## 〇、总原则（四条不可违反）

1. **四张 xlsx 为权威统计基线，docx/pdf 为派生参考**。任何口径冲突按优先级裁决：**xlsx ＞ docx ＞ 推断**。
2. **凡对不上基线的数据 → 剔除，并在表上同步记录**（剔除清单：来源 / 数量 / 处置 / 状态）。
3. **不强行裁到基线**：差异先登记【待核】挂起，待源数据补全后再定剔除。
4. 所有产物**脱敏后**才可进入 `06-实例数据/`；原始数据留在 `01-资料/`（不入库）。

## 二、接入前置：范围对照（Scope Reconciliation）

- 每次新源接入前，先做**四维度计数对照**：街道 / 社区 / 小区 / 楼栋 ↔ 预期基线（5 / 53 / 404 / 3599）。
- 工具：`06-实例数据/四表范围对照表/_gen_scope_recon.py`（可重跑，`Path(__file__)` 定位）。
- 产出：对照矩阵 + 剔除清单（§五）。
- **目的**：先确认“对得上”，再谈“算得对”。

## 三、Excel 读取硬坑（必读，已实踩）

1. **合并单元格陷阱**：`openpyxl` 只读合并区**左上角（锚点值）**，其余返回空。→ 必须手动展开 `merged_cells.ranges` 做 forward-fill（`mmap[cell.coordinate] = anchor_value`）。
   - 案例：小区表「社区」列 86.9% 看似空 → 实为合并单元格；展开后 404 小区**全匹配 53 社区，0 空**。
2. **伪表头污染**：合并单元格可能把表头行名带进数据首行。
   - 案例：小区表 R3 表头“街道名称”合并污染 R4 首行 → 405 行/54 键；剔除伪行后 **404/53**。
3. **空行 / 空主键**：直接剔除，不计入权威数。
4. **楼栋号缺失假性重复**：去重前先补楼栋号，区分“真重复 vs 录入缺失”（某小区 8 栋共用楼栋号，系录入缺失而非真重复）。
5. **双层表头**：台账多为分层表头（如指标 1–9 子旗标），需定位数据起始行再读。

## 四、指标匹配：按名不按号（双编号陷阱）

- **两套编号**：25 年数据用「2025 手册编号」，我方用「2026 建办科〔2026〕16号 55 项编号」。
  - 街区维度 1:1 对齐，错位恒 −3（25 年 N = 26 年 N−3）；**其余维度错位不固定，禁算术映射**。
- **规则**：凡跨源取指标，**一律按指标名（中文名 / formula）交叉比对**，再回写编号。
- **反向断言**：每个确定映射断言“来源名含校验 token”，防记错编号（已用于 城区29项真实结果值抽取）。
- **T 系列**（T1–T9 自治区特色指标）按约定不拆解、不接入 2026 五十五项。

## 五、剔除与同步纪律（大王硬约定）

- 凡与权威基线**对不上**的数据 → 剔除。
- 每次剔除 → 在对照表/对账表**同步标注**：来源 / 数量 / 处置 / 状态。
- **只保留一致子集**：route1 经验——“两份材料冲突，取相同、不同全部剔除”，生成器设 `consistent_codes()` 过滤器，报表与 ABox 只输出一致子集。
- **差异挂起**：不强行裁到基线，差异登记【待核】。
  - 例：社区表“社区管辖小区数”自报 Σ=409（vs 权威 404，+5，自填口径偏多）→ 不逐条剔除，以 404 为权威，差异【待核】。
  - 例：楼栋表 3592(原始)/3560(去重) vs 3599，差 原始−7/去重−39 →【待核·源数据补全楼栋号】。

## 六、脱敏红线（对外发布前必查）

- 真实地名 / 街道 / 社区 / 小区 / 楼栋原名 → 占位符：**街道 A–E、小区 `RQ_Rxxx`、楼栋 `BD_xxx`、城区 `UD01`**。
- **映射表（真名↔编号）存 `01-资料/_脱敏映射/`**，不入库——映射表入库即脱敏失效。
- 发布前用**本地敏感词表**扫描本目录全部 `.md/.yaml/.ttl`，命中数必须 **0**（脚本内不硬编码真名）。
- 例外：公开立法信息（如《××市城市更新条例》）、手册/标准公开参数可保留原名。

## 七、输出与校验规范

| 项 | 规范 | 坑 |
|---|---|---|
| 编码 | UTF-8 | — |
| 换行 | **CRLF=0**，`csv.writer(..., lineterminator="\n")` | 默认 `\r\n` 会致 CRLF=31 硬伤 |
| 断言前置 | 读取后先断言（社区=53、各列齐备、计数对齐） | 直接算易带入脏数据 |
| 负向测试 | 构造全零/全空输入，验证派生归零不崩 | 仅正向易漏边界 |
| 可复现 | mock 随机用固定 seed（如 20261114） | 随机不可复现难复核 |
| 路径定位 | 生成器一律 `Path(__file__)` | 绝对路径硬编码易跑旧文件 |
| 盘符路径 | `E:` 盘用正斜杠绝对路径 | 反斜杠 `00-01\个人` 被解析为两级目录，落错目录 |
| 目录分隔 | 用 `/` | 反斜杠致路径歧义 |
