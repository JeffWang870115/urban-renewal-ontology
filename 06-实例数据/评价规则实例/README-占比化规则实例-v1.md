## 四、脱敏（D1 先例）

- 公开 TTL **不含**任何精确真值（255/2333/58635/7.09 等经独立复核均 0 命中）；
- 精确值写本地 `01-资料/<地方>/_脱敏映射/评价规则实测值对照.csv`（**不入库**，目录名运行时动态发现，不含真名）；
- 公开版 `AssessmentResult` 用 `rdfs:comment` 写量级（百级/千级/万级）。
