## 一、三条铁律（不可违反）

1. **脱敏先行**：任何进入本目录的文件，**不得出现**真实地名、街道名、社区名、小区名、楼栋原编号。
2. **映射表不在此处**：真名 ↔ 脱敏编号的对照表存放于 `01-资料/样本成果/_脱敏映射/`（不入库）。**映射表一旦入库，脱敏即失效。**
3. **只由生成器产出**：本目录的实例文件（`.ttl` / `.yaml`）由 `03-本体模型/_gen_abox.py`（W-C02）生成，**不手工编辑**；手工改会在下次重跑时被覆盖。
